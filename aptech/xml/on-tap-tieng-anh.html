Session 1: Introduction to XML (Check Your Progress)

1. What does XML stand for?
Explanation: XML stands for Extensible Markup Language, designed to store and transport data in a self-descriptive text format.
2. Which XML technology is used to transform XML data into different formats, such as HTML or PDF?
Explanation: XSLT (Extensible Stylesheet Language Transformations) transforms XML documents into HTML, XHTML, plain text, or PDF documents.
3. In DTD, the "element" Keyword is used to:
Explanation: In a Document Type Definition (DTD), <!ELEMENT> rules declare elements and specify allowed child elements or data content models.
4. Which technology is commonly used to validate XML documents against an XML schema?
Explanation: XSD (XML Schema Definition) specifies rules, data types, and structural validation constraints for XML files.
5. XML Schema is used to:
Explanation: An XML Schema defines the structure, element hierarchy, attributes, and data types to ensure valid XML documents.

Session 2: XML Parsing and Processing (Check Your Progress)

1. ______________ is used to read, examine, and comprehend XML documents.
Explanation: An XML Parser reads XML files, verifies syntax rules, and provides API access to extract data.
2. Which of the following depicts the hierarchical organization of the XML text?
Explanation: The Document Object Model (DOM) loads an entire XML file in memory as a tree hierarchy of nodes.
3. What is used by an XML document to represent a tree-like structure using a programming interface?
Explanation: XML DOM presents an XML document as a tree structure of nodes (elements, attributes, text) accessible via standard APIs.
4. What do programming languages such as Java and Python employ to modify and interact with XML document?
Explanation: Languages use XML DOM Parsers to inspect, mutate, create, or modify nodes in XML document trees.
5. Which type of XML databases store and manage XML data in its original format?
Explanation: Native XML databases (NXD) store XML documents in native hierarchical format without converting them to relational tables.

Session 3: XPath Navigation (3.8 Check Your Progress)

1. The hierarchy of the elements or attributes in the XML document is represented by a sequence of path steps separated by __________.
Explanation: XPath uses forward slashes (/) to separate step navigation through document hierarchy (e.g. /catalog/book/title).
2. Which language is used to pick out specific elements from an XML document?
Explanation: XPath (XML Path Language) is the query language for selecting and filtering nodes in an XML document.
3. _______________ determine where items or attributes should be located within an XML document.
Explanation: XPath Expressions pinpoint exact location steps, axes, and matching nodes inside an XML document.
4. Which of the following is NOT a primary node type in XPath?
Explanation: XPath node types include Element, Attribute, Text, Namespace, Processing-Instruction, Comment, and Root nodes. Parsing nodes do not exist in XPath.
5. What is used to describe the direction of navigation?
Explanation: Axes (such as parent::, child::, ancestor::, following-sibling::) define tree navigation direction relative to the context node.

Session 4: XSLT Transformations (4.5 Check Your Progress)

1. To indicate where nodes are located within an XML document, XSLT uses __________.
Explanation: XSLT relies heavily on XPath to navigate, select, and match target elements in the source XML file.
2. XSLT has a wide range of built-in __________ that can be used to manipulate XML data.
Explanation: XSLT includes built-in functions (for string manipulation, numbers, dates, and node set processing).
3. XSLT allows for control over how the ________ is formatted and presented.
Explanation: XSLT transforms input XML into customized output presentations (like HTML tables, text, or XML).
4. The _____________ element defines a template.
Explanation: The <xsl:template> element defines transformation rules matched against specific XPath pattern nodes.
5. ____________ are used to simplify complex expressions or hold interim results.
Explanation: <xsl:variable> elements store evaluation results to simplify complex expressions and avoid redundant computations.

Session 5: JSON & Data Representation (5.8 Check Your Progress)

1. _________ are collections of characters encased in double-quotes.
Explanation: In JSON, Strings are character sequences surrounded by double quotes (e.g. "name": "Aptech").
2. A JSON ______________ is a collection of key-value pairs.
Explanation: A JSON Object is an unordered set of name/value pairs enclosed in curly braces {}.
3. _________ is an ordered group of values enclosed in square brackets and separated by commas.
Explanation: A JSON Array is an ordered list of values enclosed in square brackets [ ].
4. _________ braces surround the JSON objects.
Explanation: JSON objects begin and end with Curly braces {}.
5. ____________ has one or more JSON objects as values for its attributes.
Explanation: A Nested JSON structure contains child JSON objects inside parent object properties.

Session 6: Working with JSON Data (6.6 Check Your Progress)

1. Which JSON data structure is used for an unordered collection of key-value pairs?
Explanation: A JSON Object represents an unordered collection of key-value pairs.
2. What is the primary purpose of a JSON schema?
Explanation: JSON Schema defines the format, required fields, and allowed data types to validate JSON payloads.
3. In JavaScript, which method is used to convert a JavaScript object to a JSON string?
Explanation: JSON.stringify() serializes a JavaScript object into a JSON formatted string.
4. When parsing a JSON string with JavaScript, which of the following will throw an error if JSON is invalid?
Explanation: JSON.parse() parses a JSON text string and throws a SyntaxError if the string is malformed.
5. Which of the following is NOT a valid JSON data type?
Explanation: JSON defines Number (floating-point/decimal), but does not have a separate Integer or Function data type.

Session 7: Web APIs and JSON Transmission (7.8 Check Your Progress)

1. Which HTTP method typically sends JSON data in an HTTP request?
Explanation: POST (and PUT) HTTP methods carry request body payloads containing JSON structured data.
2. In which programming language is the JSON module commonly used for handling JSON data?
Explanation: In Python, the standard built-in json library is imported (`import json`) for parsing and serializing JSON.
3. Which of the following is NOT an essential aspect of Web APIs?
Explanation: While rate limiting is a traffic management strategy, it is not an essential structural component of API data interchange standards.
4. Which characteristic makes JSON an excellent choice for data transmission over the Web?
Explanation: Human-readability, lightweight syntax, and universal language parsing make JSON optimal for web APIs.
5. Which of the following is NOT a consideration for data portability when working with JSON data?
Explanation: API rate limiting is a operational network throttling mechanism, not a data portability issue.

Session 8: CORS & Same-Origin Policy (8.7 Check Your Progress)

1. What does CORS stand for in Web development?
Explanation: CORS stands for Cross-Origin Resource Sharing.
2. Which community is responsible for defining the CORS protocol as part of the Fetch standard?
Explanation: WHATWG maintains the Fetch standard which defines modern CORS protocols.
3. When does a CORS-preflight request occur?
Explanation: A preflight OPTIONS request occurs when cross-origin HTTP requests use non-simple methods (PUT, DELETE) or custom headers.
4. What does the Same-Origin Policy (SOP) primarily authorize a browser to do?
Explanation: The Same-Origin Policy (SOP) restricts web scripts from reading resources unless they match the same origin (protocol, host, port).
5. What is an 'Origin' composed of in a CORS context?
Explanation: An Origin tuple consists of the URI scheme (protocol), hostname (domain), and port number.
