1.2 Phân Biệt DTD vs XML Schema (XSD)

Tiêu chí so sánh DTD (Document Type Definition) XML Schema (XSD)
Cú pháp Cú pháp phi-XML ngắn gọn kiểu EBNF. Cú pháp XML chuẩn (<xs:schema>).
Kiểu dữ liệu Chỉ hỗ trợ dữ liệu chuỗi văn bản (#PCDATA, CDATA). Hỗ trợ hơn 40 kiểu dữ liệu chuẩn (int, float, date, string...).
Không gian tên (Namespace) Không hỗ trợ Namespace. Hỗ trợ đầy đủ XML Namespaces.
