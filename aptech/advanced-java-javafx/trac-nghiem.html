CÂU HỎI TRẮC NGHIỆM ADVANCED JAVA & JAVAFX

Câu 1: Which of these statements related to java.util package are true?
Giải thích chi tiết:
Đáp án đúng: A & B
• A đúng: Giao diện Collection đại diện cho một nhóm các đối tượng (phần tử) được quản lý như một đơn vị duy nhất.
• B đúng: Collections Framework cung cấp tập hợp đồng bộ các Interfaces (List, Set, Map, Queue) và Classes (ArrayList, HashSet, HashMap...) để lưu trữ và thao tác dữ liệu.
• C sai: Collections Framework được thiết kế để có tính tương thích và chuyển đổi cao (high interoperability).
• D sai: Giao diện Collection nằm ở đỉnh của phân cấp khung tập hợp (Collection Hierarchy) cho List, Set, Queue.
Câu 2: Which of these statements regarding Lists are true?
Giải thích chi tiết:
Đáp án đúng: A & D
• A đúng: List là tập hợp có thứ tự (ordered collection), hỗ trợ truy cập phần tử dựa trên chỉ số vị trí (Index-based access: list.get(index)).
• B sai: List cung cấp các phương thức tìm kiếm như indexOf(), lastIndexOf(), contains().
• C sai: ArrayList() khởi tạo một List rỗng với dung lượng mặc định (default capacity = 10), không phải tạo một mảng cố định rỗng.
• D đúng: Vector là một mảng động (dynamic re-sizable array) có thể tự động tăng hoặc giảm kích thước theo nhu cầu.
Câu 3: The getFirst() method ________ .
Giải thích chi tiết:
Đáp án đúng: B
• Phương thức getFirst() trong LinkedList / Deque có nhiệm vụ lấy ra (Retrieves) nhưng không xóa (does NOT remove) phần tử đầu tiên của danh sách.
• Nếu muốn vừa lấy ra vừa xóa phần tử đầu tiên, ta dùng phương thức removeFirst() hoặc pop() / pollFirst().
• Ngược lại, getLast() lấy phần tử cuối mà không xóa.
Câu 4: Which of these statements about different Set classes are true?
Giải thích chi tiết:
Đáp án đúng: A & D
• A đúng: Set là giao diện tập hợp không chấp nhận các phần tử trùng lặp (does not permit duplicate elements).
• B sai: SortedSet kế thừa từ Set nên cũng hoàn toàn KHÔNG cho phép phần tử trùng lặp.
• C sai: HashSet dựa trên Bảng băm (Hash Table), không đảm bảo bất kỳ thứ tự nào của các phần tử.
• D đúng: LinkedHashSet duy trì thứ tự chèn phần tử (Insertion Order) nhờ kết hợp Hash Table và Doubly-linked list.
Câu 5: Which of these statements related to different classes implementing Map interface are true?
Giải thích chi tiết:
Đáp án đúng: A, C, D, E (và B nếu tính 1 null key)
• A đúng: TreeMap sắp xếp các Keys theo thứ tự tự nhiên (Natural ordering) hoặc theo Comparator.
• B đúng/chú ý: HashMap cho phép 1 key bằng null và nhiều value bằng null.
• C đúng: TreeMap lưu trữ dữ liệu dưới dạng cấu trúc Cây đỏ-đen (Red-Black Tree).
• D đúng: LinkedHashMap là sự kết hợp giữa Bảng băm (Hash map) và Danh sách liên kết (Linked list).
• E đúng: LinkedHashMap duyệt các phần tử theo đúng thứ tự chúng được thêm vào Map (Insertion order).
Câu 6: Which of these statements stating the advantages of Generics are true?
Giải thích chi tiết:
Đáp án đúng: C & E
• C đúng: Ưu điểm cốt lõi của Generics là phát hiện lỗi kiểm tra kiểu dữ liệu ở thời điểm biên dịch (Compile-time type checking), giúp lập trình viên sửa lỗi nhanh hơn rất nhiều so với lỗi thời điểm thực thi (Runtime Exception như ClassCastException).
• E đúng: Generics giúp code rõ ràng minh bạch hơn, việc đánh giá code (code review) đơn giản hơn vì kiểu dữ liệu của container được chỉ định rõ ràng.
• A sai: Generics là tính năng kiểm tra kiểu tĩnh (Static Type Checking) ở thời điểm biên dịch, không liên quan đến dynamic binding.
• B sai: Bạn hoàn toàn có thể tạo Generic Constructor (ví dụ: public <T> MyClass(T item)).
• D sai: Hoàn toàn khai báo được Key và Value khác kiểu (ví dụ: Map<String, Integer> map).
Câu 7: Which of the following statements explaining the use of wildcards with Generics are true?
Giải thích chi tiết:
Đáp án đúng: A, B, C, E
• A đúng: Ký tự đại diện ? (Unbounded Wildcard) biểu thị cho bất kỳ kiểu dữ liệu nào.
• B & C đúng: ? extends Type (Upper Bounded Wildcard) đại diện cho tập hợp các kiểu con (subtypes) kế thừa hoặc là chính kiểu Type.
• E đúng: ? super Type (Lower Bounded Wildcard) đại diện cho tập hợp các kiểu cha (supertypes) của Type.
• D sai: Khái niệm 'supertypes which is a subtype of Type' là mâu thuẫn về mặt thuật ngữ.
Câu 8: Which of the following statements specifying the use of Legacy code in Generics are true?
Giải thích chi tiết:
Đáp án đúng: A, C, D, E
• A đúng: Khi truyền một Raw Type vào nơi yêu cầu Parameterized Type, Trình biên dịch Java sẽ phát ra cảnh báo Unchecked conversion warning.
• C đúng: Khi sử dụng một Lớp Generic (như Collection) mà không khai báo tham số kiểu (Type parameter), nó được gọi là Raw Type (ví dụ: List list = new ArrayList();).
• D đúng: Cơ chế Type Erasure xóa bỏ tất cả thông tin kiểu Generic trong quá trình biên dịch để tạo ra Bytecode tương thích với các phiên bản Java cũ.
• B sai: Erasure LÀM XÓA BỎ (removes) thông tin kiểu generic, chứ KHÔNG phải thêm vào (adds).
Câu 9: When an existing piece of code works with both legacy and generic versions of the library, this is called ________ .
Giải thích chi tiết:
Đáp án đúng: C. Binary compatibility
• Trong quy chuẩn Java Generics, Binary compatibility (Tương thích nhị phân) là khả năng giúp mã nguồn cũ đã biên dịch trước đó vẫn tiếp tục chạy bình thường khi nâng cấp thư viện lên phiên bản có sử dụng Generics mà không cần phải biên dịch lại mã nguồn.
Câu 10: In the generic class declaration, the class name is followed by a ________ .
Giải thích chi tiết:
Đáp án đúng: C. Type parameter section
• Cú pháp khai báo Lớp Generic chuẩn trong Java: public class ClassName<T, E> { ... }.
• Trong đó, theo sau tên lớp (class name) là phần khai báo các tham số kiểu dữ liệu được đặt trong cặp dấu ngoặc nhọn <> (gọi là Type Parameter Section).
Câu 11: Which one of the following prefix should be added to the number to specify a binary literal?
Giải thích chi tiết:
Đáp án đúng: D. 0B
• Từ Java 7 trở đi, Java hỗ trợ hằng số nhị phân (Binary Literals).
• Để khai báo một số nguyên dưới dạng nhị phân, ta thêm tiền tố 0b hoặc 0B vào trước chuỗi chữ số 0 và 1 (ví dụ: int byteVal = 0B1010; đại diện cho giá trị 10 trong hệ thập phân).
Câu 12: Which of the following are true about stream classes?
a. They help read input from a stream.
b. Input and Output streams are used for reading and writing of structured sequence of bytes.
c. They help manage disk files.
d. All classes that work on streams directly works with files and the file system.
Giải thích chi tiết:
Đáp án đúng: (B) b
• Phát biểu b định nghĩa chính xác nhất về các lớp Byte Stream (InputStream và OutputStream): Dùng để đọc và ghi một chuỗi các byte có cấu trúc (structured sequence of bytes).
• Phát biểu d sai vì không phải tất cả các stream đều làm việc trực tiếp với file/hệ thống tập tin (ví dụ ByteArrayInputStream, PipedInputStream, Socket stream...).
Câu 13: The File(String dirpath) constructor ___________________.
Giải thích chi tiết:
Đáp án đúng: (A) a
• Constructor File(String pathname) (hoặc dirpath) khởi tạo một đối tượng File mới bằng cách chuyển đổi chuỗi đường dẫn (String path) thành một đường dẫn trừu tượng (abstract pathname).
Câu 14: Which of the following classes create a FileInputStream or FileOutputStream to contain it?
Giải thích chi tiết:
Đáp án đúng: (C) c. FileDescriptor

Câu 15: The sync method ________ .

Đáp án đúng: (D) d

Câu 16: What is the process of saving data to some permanent storage called?
Giải thích chi tiết:
Đáp án đúng: B. Persistence
• Persistence (Tính lưu trữ bền vững / Lưu trữ vĩnh viễn) là thuật ngữ chung chỉ quá trình ghi và bảo lưu trạng thái dữ liệu vào các thiết bị lưu trữ cố định (như Ổ đĩa cứng, Cơ sở dữ liệu, File hệ thống) để dữ liệu không bị mất đi khi ứng dụng kết thúc.
• Serialization là cơ chế chuyển đổi đối tượng thành chuỗi byte để thực hiện Persistence.
Câu 17: Which of these statements related to characteristics and uses of processes and threads are true?
(A) A process has a self-contained execution environment.
(B) A thread is the smallest unit of executable code in an application that performs a particular task.
(C) A thread has no definite starting point, execution steps and terminating point.
(D) A process contains one or more threads inside it.
(E) Threads can be used for playing sound and displaying images simultaneously.
Giải thích chi tiết:
Đáp án đúng: (D) A, B, D
• A đúng: Một Process (Tiến trình) sở hữu một môi trường thực thi độc lập riêng biệt (không gian bộ nhớ, bảng tài nguyên riêng).
• B đúng: Một Thread (Luồng) là đơn vị thực thi nhỏ nhất của mã nguồn trong một ứng dụng.
• D đúng: Một Process có thể chứa một hoặc nhiều Thread cùng chạy bên trong nó.
• C sai: Thread có điểm bắt đầu (khi gọi run()/start()), các bước thực thi và điểm kết thúc xác định.
Câu 18: Which of the following code snippets creates a thread object and makes it runnable?
Giải thích chi tiết:
Đáp án đúng: (A)

Câu 19: Which of these statements regarding different states of a thread are true?
(A) A thread in the waiting state is alive but not running.
(B) A thread is considered terminated when its run() method starts.
(C) A thread is in a blocked state when it is waiting for the lock of another object.
(D) The thread comes out of the runnable state when the start() method is invoked on it.
(E) A new thread is an empty thread object with no system resources allocated.
Giải thích chi tiết:
Đáp án đúng: (A) A, C, E
• A đúng: Luồng ở trạng thái WAITING vẫn còn sống (alive) nhưng tạm thời ngưng chạy để chờ tín hiệu.
• C đúng: Luồng ở trạng thái BLOCKED khi nó đang chờ cấp quyền sở hữu Monitor Lock của một đối tượng khác.
• E đúng: Đối tượng Thread mới khởi tạo (trạng thái NEW) chưa được cấp phát tài nguyên hệ điều hành cho tới khi phương thức start() được gọi.
• B sai: Thread chỉ kết thúc (terminated) khi phương thức run() chạy xong hoàn toàn.
• D sai: Phương thức start() đưa Thread VÀO trạng thái RUNNABLE.
Câu 20: Which of the following method declarations of the Thread class are true?
(A) public void interrupt()
(B) static void Sleep(long millis)
(C) public void run()
(D) thread.start()
(E) public String getName()
Giải thích chi tiết:
Đáp án đúng: (C) A, C, E
• A đúng: public void interrupt() là phương thức gửi tín hiệu ngắt luồng.
• C đúng: public void run() là phương thức chứa mã thi hành của luồng.
• E đúng: public String getName() là phương thức lấy tên gọi của luồng.
• B sai: Trong Java tên phương thức viết thường chữ cái đầu: public static void sleep(long millis) throws InterruptedException.
• D sai: thread.start() là câu lệnh gọi phương thức, không phải cú pháp khai báo phương thức.
Câu 21: Which of these statements regarding the priority of threads are true?
(A) The getPriority() method retrieves the current priority of any thread.
(B) The setPriority() method changes the current priority of any thread.
(C) Thread priorities are numbers and range from Thread.MIN_PRIORITY to Thread.MAX_PRIORITY.
(D) A newly created thread inherits the priority of its parent thread.
(E) The higher the integers, the lower are the priorities.
Giải thích chi tiết:
Đáp án đúng: (B) A, B, C, D
• A đúng: getPriority() lấy giá trị độ ưu tiên hiện tại của luồng.
• B đúng: setPriority(int newPriority) thay đổi độ ưu tiên của luồng.
• C đúng: Mức độ ưu tiên luồng nằm trong khoảng từ Thread.MIN_PRIORITY (1) đến Thread.MAX_PRIORITY (10).
• D đúng: Luồng mới được tạo tự động thừa hưởng độ ưu tiên của luồng cha đã tạo ra nó.
• E sai: Số nguyên càng lớn thì độ ưu tiên CÀNG CAO (10 là cao nhất, 1 là thấp nhất).
Câu 22: Which of these statements about daemon threads are true?
(A) Daemon threads are service providers for other threads running in different process.
(B) Daemon threads are designed as low-level background threads that perform some tasks such as mouse events.
(C) The threads that run system code are user threads.
(D) The setDaemon() method with the argument as true will convert the user thread to a daemon thread.
(E) The isDaemon() method returns true if the thread is a user thread.
Giải thích chi tiết:
Đáp án đúng: (B) B, C, D
• B đúng: Daemon thread được thiết kế để chạy ngầm dưới nền (background tasks) cung cấp các dịch vụ hệ thống (như Garbage Collection, xử lý sự kiện ngầm).
• D đúng: Gọi setDaemon(true) trước khi gọi start() sẽ thiết lập luồng trở thành Daemon Thread.
• E sai: isDaemon() trả về true nếu luồng là Daemon thread, chứ không phải user thread.
