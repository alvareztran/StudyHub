Danh Mục Bài Học & Tài Liệu Ôn Tập

Chọn chương bài giảng bên dưới để bắt đầu học tập và luyện tập lập trình Java OOP:

  • 🇬🇧 Java OOP - English Review & Practice Question Bank

    Trang ôn tập tổng hợp các câu hỏi trắc nghiệm & bài tập lập trình bằng Tiếng Anh giữ nguyên bản 100% chuẩn giáo trình Aptech Quốc tế.

  • 🎯 Ngân Hàng Trắc Nghiệm Ôn Thi APTECH Java OOP (60 Câu)

    Bộ câu hỏi trắc nghiệm chọn lọc mô phỏng đề thi Aptech Online Exam: OOP 4 trụ cột, Exception handling, Collections Framework, Streams I/O và Java Swing với đáp án & giải thích tức thì.

  • Chương 1: Tổng quan Ngôn ngữ Java & Nền tảng Cú pháp APTECH

    Lịch sử phát triển Java, kiến trúc máy ảo JVM, JRE, JDK, quy trình biên dịch bytecode, kiểu dữ liệu nguyên thủy vs tham chiếu, biến, toán tử và cấu trúc điều khiển rẽ nhánh, vòng lặp.

  • Chương 2: Lớp (Class), Đối Tượng (Object) & Constructor

    Phương pháp luận thiết kế Lớp và Đối tượng, thuộc tính, phương thức, Constructor Overloading, từ khóa this, phạm vi truy cập Access Modifiers và biến/phương thức tĩnh static.

  • Chương 3: Bốn Tính Chất Cốt Lõi Của OOP (4 Core OOP Pillars)

    Phân tích chi tiết 4 trụ cột OOP: Đóng gói (Encapsulation), Kế thừa (Inheritance - extends, super), Đa hình (Polymorphism - Overloading vs Overriding, Dynamic Binding) và Trừu tượng (Abstraction - abstract class vs interface).

  • Chương 4: Xử Lý Ngoại Lệ (Exception Handling) trong Java

    Cấu trúc cây Throwable (Checked Exception vs Unchecked Exception), khối try-catch-finally, từ khóa throw, throws và quy trình xây dựng Custom Exception cho dự án Aptech eProject.

  • Chương 5: Java Collections Framework & Generics

    Khám phá bộ sưu tập dữ liệu Java: List (ArrayList, LinkedList), Set (HashSet, TreeSet), Map (HashMap, TreeMap), giao diện Comparable vs Comparator và Kỹ thuật Generics <T>.

  • Chương 6: Java I/O Streams, Thao Tác File & Serialization

    Xử lý luồng dữ liệu Byte Stream vs Character Stream, đọc ghi tập tin văn bản/nhị phân với BufferedReader, BufferedWriter, giao diện Serializable và từ khóa transient.

  • Chương 7: Lập Trình Giao Diện Đồ Họa Java Swing & Xử Lý Sự Kiện

    Xây dựng ứng dụng Desktop GUI với Java Swing: JFrame, JPanel, JButton, JTable, các Layout Manager (BorderLayout, FlowLayout, GridLayout) và mô hình Event-Driven Programming với ActionListener.
