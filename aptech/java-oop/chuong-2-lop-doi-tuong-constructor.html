CHƯƠNG 2. LỚP (CLASS), ĐỐI TƯỢNG (OBJECT) & CONSTRUCTOR

Phương pháp luận thiết kế Lớp/Đối tượng, Constructor, Access Modifiers, từ khóa this & static.

2.1 Khái Niệm Lớp (Class) Và Đối Tượng (Object)

Trong lập trình hướng đối tượng (OOP):

  • Lớp (Class): Là bản thiết kế (blueprint/template) định nghĩa các thuộc tính (attribute) và hành vi (method) chung của một nhóm đối tượng.
  • Đối tượng (Object): Là một thực thể cụ thể (instance) được tạo ra từ bản thiết kế lớp, chiếm giữ vùng nhớ trong RAM.
// Định nghĩa lớp SinhVien trong chuẩn Aptech public class SinhVien { // Thuộc tính (Instance variables) private String maSV; private String hoTen; private double diemTB; // Constructor mặc định (No-arg constructor) public SinhVien() { this.maSV = "SV000"; this.hoTen = "Chưa cập nhật"; this.diemTB = 0.0; } // Constructor có tham số (Parameterized constructor) public SinhVien(String maSV, String hoTen, double diemTB) { this.maSV = maSV; this.hoTen = hoTen; this.diemTB = diemTB; } // Phương thức hiển thị thông tin public void hienThiThongTin() { System.out.println("MSSV: " + this.maSV + " | Họ tên: " + this.hoTen + " | ĐTB: " + this.diemTB); } }

2.3 Thành Phần Tĩnh (Static Members) & Từ khóa `this`

  • Từ khóa `this`: Tham chiếu đến chính đối tượng hiện tại đang thực thi phương thức/constructor. Dùng để phân biệt thuộc tính lớp và tham số trùng tên.
  • Từ khóa `static`: Thuộc tính hoặc phương thức tĩnh thuộc về cấp độ Lớp (Class level), được chia sẻ chung cho tất cả các đối tượng mà không cần khởi tạo `new`.
public class StudentCounter { public static int totalStudents = 0; // Biến static đếm số sinh viên public StudentCounter() { totalStudents++; // Tăng biến tĩnh mỗi khi tạo 1 instance mới } public static void displayTotal() { System.out.println("Tổng số sinh viên đã khởi tạo: " + totalStudents); } }
