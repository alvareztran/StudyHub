CHƯƠNG 3. BỐN TÍNH CHẤT CỐT LÕI CỦA OOP (4 CORE OOP PILLARS)

Phân tích Đóng gói, Kế thừa, Đa hình và Trừu tượng (Abstract Class vs Interface).

3.1 Tính Đóng Gói (Encapsulation)

Đóng gói là kỹ thuật che giấu dữ liệu bên trong lớp (dùng private) và chỉ cho phép truy cập/sửa đổi thông qua các phương thức công khai (Getters & Setters) có kiểm tra tính hợp lệ.

public class Account { private double balance; // Che giấu thuộc tính public double getBalance() { return this.balance; } public void deposit(double amount) { if (amount > 0) { this.balance += amount; } else { System.out.println("Số tiền nạp không hợp lệ!"); } } }

3.2 Tính Kế Thừa (Inheritance)

Cho phép một lớp con (Subclass/Derived Class) thừa hưởng các thuộc tính và phương thức từ lớp cha (Superclass/Base Class) bằng từ khóa extends. Sử dụng từ khóa super để gọi constructor hoặc phương thức của lớp cha.

// Lớp cha public class NhanVien { protected String ten; protected double luongCoBan; public NhanVien(String ten, double luongCoBan) { this.ten = ten; this.luongCoBan = luongCoBan; } public double tinhLuong() { return this.luongCoBan; } } // Lớp con kế thừa từ NhanVien public class NhanVienKhoaHoc extends NhanVien { private double phuCap; public NhanVienKhoaHoc(String ten, double luongCoBan, double phuCap) { super(ten, luongCoBan); // Gọi constructor lớp cha this.phuCap = phuCap; } @Override public double tinhLuong() { // Ghi đè phương thức (Method Overriding) return super.tinhLuong() + this.phuCap; } }

3.3 Tính Đa Hình (Polymorphism)

Cho phép một hành vi có thể thể hiện dưới nhiều hình thức khác nhau:

  • Đa hình thời gian biên dịch (Compile-time Polymorphism): Thực hiện thông qua Method Overloading (nạp chồng phương thức cùng tên nhưng khác tham số trong cùng 1 class).
  • Đa hình thời gian chạy (Runtime Polymorphism): Thực hiện thông qua Method Overriding (ghi đè phương thức lớp con) và cơ chế Dynamic Binding.

3.4 Tính Trừu Tượng (Abstraction): Abstract Class vs Interface

Tiêu chí so sánh Lớp trừu tượng (Abstract Class) Giao diện (Interface)
Từ khóa sử dụng abstract class (Kế thừa dùng extends) interface (Thực thi dùng implements)
Đa kế thừa Không (Chỉ đơn kế thừa 1 lớp cha) Có (1 lớp có thể thực thi nhiều Interface)
Các loại phương thức Chứa được cả phương thức trừu tượng và phương thức thường có body. Chứa phương thức trừu tượng, `default` method và `static` method (Java 8+).
Thuộc tính biến Chứa được biến thường, biến static, final. Mặc định mọi biến đều là public static final (hằng số).
// Ví dụ định nghĩa Interface trong Java public interface Drawable { void draw(); // Phương thức trừu tượng } public class Circle implements Drawable { @Override public void draw() { System.out.println("Vẽ hình tròn."); } }
