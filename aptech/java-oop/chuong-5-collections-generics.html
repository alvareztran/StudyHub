CHƯƠNG 5. JAVA COLLECTIONS FRAMEWORK & GENERICS

Phân tích List, Set, Map, Comparable vs Comparator và Kỹ thuật Generics.

5.1 Cấu Trúc Khung Bộ Sưu Tập Java Collections Framework

Java Collections cung cấp các cấu trúc dữ liệu tối ưu có sẵn thuộc gói java.util:

Giao diện (Interface) Lớp triển khai phổ biến Đặc điểm cấu trúc & Hành vi
List ArrayList, LinkedList Danh sách có thứ tự, cho phép lưu trữ các phần tử trùng lặp, truy cập theo chỉ số index.
Set HashSet, TreeSet Tập hợp **KHÔNG chứa phần tử trùng lặp**. TreeSet tự động sắp xếp phần tử.
Map HashMap, TreeMap Lưu trữ dữ liệu dạng cặp **Key - Value**. Key là duy nhất không trùng lặp.

5.2 Ví Dụ Lập Trình Với List, Map & Comparable / Comparator

import java.util.*; // Lớp Student thực thi Comparable để tự định nghĩa tiêu chuẩn sắp xếp mặc định class Student implements Comparable { String name; double gpa; public Student(String name, double gpa) { this.name = name; this.gpa = gpa; } @Override public int compareTo(Student o) { return Double.compare(o.gpa, this.gpa); // Sắp xếp giảm dần theo GPA } } public class CollectionDemo { public static void main(String[] args) { List list = new ArrayList<>(); list.add(new Student("An", 3.8)); list.add(new Student("Bình", 3.2)); list.add(new Student("Cường", 3.9)); Collections.sort(list); // Sắp xếp theo compareTo for (Student s : list) { System.out.println(s.name + " - GPA: " + s.gpa); } } }
