CHƯƠNG 1. TỔNG QUAN NGÔN NGỮ JAVA & NỀN TẢNG CÚ PHÁP APTECH

Lịch sử Java, kiến trúc JVM/JRE/JDK, kiểu dữ liệu, toán tử và cấu trúc điều khiển.

1.1 Kiến Trúc Nền Tảng Java: JDK, JRE & JVM

Ngôn ngữ Java tuân theo triết lý nổi tiếng "Write Once, Run Anywhere" (WORA). Nguyên lý này đạt được nhờ kiến trúc phân lớp của môi trường thực thi Java:

Thành phần Viết tắt của Chức năng & Vai trò chi tiết
JDK Java Development Kit Bộ công cụ phát triển phần mềm dành cho lập trình viên, bao gồm trình biên dịch javac, trình đóng gói jar, javadoc và môi trường JRE.
JRE Java Runtime Environment Môi trường chạy ứng dụng Java, chứa các thư viện lớp chuẩn (Java Class Libraries) và Máy ảo Java (JVM).
JVM Java Virtual Machine Máy ảo thực thi mã Bytecode (file .class), chịu trách nhiệm thông dịch/JIT compile sang mã máy vật lý và tự động dọn rác (Garbage Collection).

Quy trình biên dịch và thực thi chương trình Java:

Source Code (Hello.java) ──[ javac Compiler ]──> Bytecode (Hello.class) ──[ JVM Interpreter / JIT ]──> Machine Code (0101...)

1.2 Phân Loại Kiểu Dữ Liệu Trong Java

Java quản lý 2 nhóm kiểu dữ liệu chính:

  • Kiểu nguyên thủy (Primitive Data Types): Lưu trực tiếp giá trị trong bộ nhớ Stack (gồm 8 kiểu: byte, short, int, long, float, double, char, boolean).
  • Kiểu tham chiếu (Reference Data Types): Lưu địa chỉ vùng nhớ trỏ đến đối tượng nằm trong bộ nhớ Heap (như Class, Array, Interface, String).
// Ví dụ khai báo biến và hằng số trong Java public class Main { public static void main(String[] args) { int count = 100; double price = 99.99; boolean isActive = true; char grade = 'A'; final double PI = 3.14159; // Hằng số với từ khóa final System.out.println("Count: " + count + ", Price: " + price); } }

1.3 Cấu Trúc Điều Khiển & Vòng Lặp

Java hỗ trợ đầy đủ các cấu trúc điều khiển chuẩn:

// 1. Cấu trúc rẽ nhánh if-else & switch-case int score = 85; if (score >= 90) { System.out.println("Xuất sắc"); } else if (score >= 75) { System.out.println("Giỏi"); } else { System.out.println("Khá/Trung bình"); } // 2. Vòng lặp for, while, do-while & Enhanced For-each int[] numbers = {10, 20, 30, 40, 50}; for (int num : numbers) { System.out.println("Giá trị: " + num); }
