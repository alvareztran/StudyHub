CHƯƠNG 4. XỬ LÝ NGOẠI LỆ (EXCEPTION HANDLING) TRONG JAVA

Cấu trúc Throwable, Checked vs Unchecked Exception, try-catch-finally và Custom Exception.

4.1 Cấu Trúc Cây Ngoại Lệ Trong Java

Tất cả các loại ngoại lệ và lỗi trong Java đều bắt nguồn từ lớp java.lang.Throwable, được chia làm 2 nhánh chính:

  • Error: Lỗi nghiêm trọng thuộc hệ thống/JVM (như OutOfMemoryError, StackOverflowError), ứng dụng không nên catch.
  • Exception: Lỗi phát sinh trong quá trình chạy chương trình có thể bắt và xử lý được. Chia làm 2 loại:
    • Checked Exception: Bắt buộc phải xử lý tại thời điểm biên dịch (như IOException, SQLException).
    • Unchecked Exception (RuntimeException): Lỗi logic tại thời điểm chạy (như NullPointerException, ArithmeticException, ArrayIndexOutOfBoundsException).

4.2 Khối `try-catch-finally` & Từ khóa `throw` / `throws`

public class ExceptionDemo { // Sử dụng throws để khai báo phương thức có thể quăng ra Exception public static int divide(int a, int b) throws ArithmeticException { if (b == 0) { throw new ArithmeticException("Lỗi: Không thể chia cho số 0!"); } return a / b; } public static void main(String[] args) { try { int result = divide(10, 0); System.out.println("Kết quả: " + result); } catch (ArithmeticException e) { System.err.println("Đã bắt ngoại lệ: " + e.getMessage()); } finally { System.out.println("Khối finally LUÔN LUÔN được thi hành để dọn dẹp tài nguyên."); } } }

4.3 Xây Dựng Custom Exception Trong Aptech eProject

// Lớp Ngoại lệ tự định nghĩa public class InvalidAgeException extends Exception { public InvalidAgeException(String message) { super(message); } } // Sử dụng Custom Exception public void checkTuoi(int tuoi) throws InvalidAgeException { if (tuoi < 18) { throw new InvalidAgeException("Tuổi phải từ 18 trở lên!"); } }
