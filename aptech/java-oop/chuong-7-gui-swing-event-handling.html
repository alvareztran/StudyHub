CHƯƠNG 7. LẬP TRÌNH GIAO DIỆN ĐỒ HỌA JAVA SWING & XỬ LÝ SỰ KIỆN

Xây dựng Desktop GUI với JFrame, JButton, JTable, Layout Managers và Event Handling.

7.1 Lập Trình Giao Diện Đồ Họa Đơn Giản Với Java Swing

Java Swing cung cấp bộ các component GUI thuộc gói javax.swing:

import javax.swing.*; import java.awt.event.*; public class MyGuiApp { public static void main(String[] args) { JFrame frame = new JFrame("Aptech Java Swing Demo"); JButton btn = new JButton("Click Me!"); btn.setBounds(100, 80, 120, 40); // Xử lý sự kiện click nút bằng Lambda Expression btn.addActionListener(e -> { JOptionPane.showMessageDialog(frame, "Xin chào từ Java Swing APTECH!"); }); frame.add(btn); frame.setSize(340, 240); frame.setLayout(null); frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); frame.setVisible(true); } }
