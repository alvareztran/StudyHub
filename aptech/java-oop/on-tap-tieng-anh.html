Session 1: Introduction to Java (1.13 Check Your Progress)

1. Which of the following features of Java programming languages allows to execute multiple tasks concurrently?
Explanation: Multithreading in Java enables a program to execute multiple threads concurrently for maximum CPU utilization and responsive multitasking.
2. Match the following terms against their corresponding description:
TermDescription
a. Object1. Represents behavior of an object
b. Class2. Represents state of an object
c. Field3. Template or blueprint
d. Method4. Instance of class
Explanation: Object is an instance of a class (a-4), Class is a template/blueprint (b-3), Field represents state (c-2), and Method represents behavior (d-1).
3. Which of the following statements are true regarding Java platform and its components?
a. Java platform provides an environment for developing applications that can be executed only on Java hardware and OS
b. Java API is a large collection of ready-made software components
c. JVM is a comprehensive set of development tools used for developing applications
d. There are different implementations of JVM available for different platforms
e. Java APIs are used to run a Java program
Explanation: Statement b is true (Java API is a collection of prebuilt packages) and statement d is true (different JVM implementations exist for Windows, Linux, macOS).
4. Which of these statements about compiling and executing a Java program are true?
a. The javac tool invokes the Java compiler
b. The java tool invokes the Java interpreter
c. The .class files contain bytecodes
d. The Java interpreter checks for the syntax, grammar, and data types of the program
e. The Java interpreter compiles the code
Explanation: Statements a (javac compiles), b (java interprets/runs), and c (.class contains bytecode) are correct. Syntax/grammar checks are done by javac during compilation, not runtime.
5. _______ defines a namespace that stores classes with similar functionalities in them.
Explanation: A Package in Java is used to group related classes and interfaces, acting as a unique namespace container.

Session 3: Decision-Making Constructs and Loops (3.11 Check Your Progress)

1. You are using a Code Snippet to print the value of sum as '6'. Which of the following Code Snippet will help you to achieve this?
Explanation: Tracing Option (C):
• Iteration 1: number = 1, sum = 1. Condition sum > 4 is false.
• Iteration 2: number = 2, sum = 1 + 2 = 3. Condition sum > 4 is false.
• Iteration 3: number = 3, sum = 3 + 3 = 6. Condition sum > 4 (6 > 4) is TRUE ⇒ break executes, printing 6!
2. You want the output to be displayed as '95 91 87 83'. Can you arrange the steps in sequence to achieve the same?
a. System.out.println(i);
b. i++; }
c. int i = 100;
d. i -= 5;
e. while(i >= 85) {
Explanation: Sequence: c (init 100) → e (while loop) → d (i -= 5) → a (print i) → b (i++). Iteration steps: 100-5=95 (print 95, ++=96) → 96-5=91 (print 91, ++=92) → 92-5=87 (print 87, ++=88) → 88-5=83 (print 83, ++=84, terminates).
3. Which of the following statements about do-while statements are true?
a. do-while statement tests the condition after the first iteration of the loop
b. In do-while, if the condition is true, the control passes back to the top of the loop
c. In do-while, if the condition is true, the loop terminates
d. do-while statements is executed at least once
e. do-while tests the condition at the beginning of the loop
Explanation: Statements a (tests condition at the end), b (true condition loops back), and d (always executes at least once) are true.

Session 4: Classes, Objects, and Methods (4.12 Check Your Progress)

1. Which of the following statements stating the characteristics of classes are true?
a. Class names cannot be a keyword in Java
b. Class names can be in mixed case
c. Declaration of the class are not required to be preceded with the keyword class
d. Class names can begin with a digit
Explanation: Class names cannot be reserved keywords (a) and can use mixed case / PascalCase naming convention (b).
2. Which of the following methods have the same name as class name?
Explanation: A Constructor must have the exact same name as the class in which it is defined and has no return type.
4. In Java, ________ provides a way to create an object and initialize its fields, before the constructor methods are invoked.
Explanation: Object Initializers (Instance Initializer Blocks { ... }) run when an object is instantiated, right before the constructor is executed.
5. Which of the following options specifies a feature of OOP language that hides the instance variables within the class?
Explanation: Data Encapsulation hides field variables inside the class (by making them private) and exposes public getter/setter methods for controlled access.

Session 5: Arrays and Strings (5.5 Check Your Progress)

1. ________ objects are similar to String objects, except that they are mutable.
Explanation: StringBuilder objects represent mutable sequences of characters, whereas standard String objects are immutable.
2. Which of the following statements about an array are true?
a. An array is a container object that can hold a fixed number of values of a single type
b. The first index begins with zero and the index of last element is always equal to the length
c. After creation of the array, its length becomes fixed
d. Values of an array are stored at scattered locations in memory
Explanation: Statements a (holds fixed number of same type) and c (fixed length after creation) are true. Last index is length - 1 and elements are stored contiguously.

4. Which of the following options will declare and initialize a single-dimensional array?
Explanation: Option (B) is the valid shorthand array literal syntax for declaring and initializing an int[] array.
5. Consider the following Code Snippet: Integer x = 10; // line 1 int y = x; // line 2 int x1 = 10; float z = x1; // line 3 int w = (int)z; // line 4 Match the Code Snippet at following lines with the corresponding Java feature:

Session 6: Modifiers and Packages (6.5 Check Your Progress)

1. Every Java application or applet has access to the ________ core package in the Java API.
Explanation: The java.lang package is automatically imported by default into all Java compilation units.
2. Which of the following statements about the final modifier are true?
a. The final modifier is used when modification of a class or data member is to be restricted
b. A method declared final must be overridden
c. A class declared final must be inherited or subclassed
d. A variable declared final is a constant whose value cannot be modified
Explanation: Statements a (restricts modification) and d (final variable is constant) are true. Final methods cannot be overridden and final classes cannot be inherited.

ModifierDescription
a. volatile1. Used with a variable, method, and class
b. native2. Applied only to fields
c. final3. Used only with instance variables
d. transient4. Used only with methods
Explanation: Matching: volatile (applied to fields, a-2), native (used with C/C++ methods, b-4), final (variable, method, class, c-1), transient (instance variables, d-3).
4. Which of the following option represents the correct command for generating a .jar file using an existing manifest file and displaying a verbose output? (Assumption: jar file - MyJar.jar, Manifest file - Manifest.txt, class file - MyClass.class, package - mypkg).
Explanation: In jar cvmf, options m and f map to the argument order: m ⇒ Manifest.txt and f ⇒ MyJar.jar.

Session 7: Inheritance and Polymorphism (7.5 Check Your Progress)

1. ________ keyword is used to access parent class constructor and methods from child class.
Explanation: The super keyword is used to access superclass constructors (`super(...)`) and methods (`super.method()`).
2. Which of the following statements about static and dynamic binding are true?
a. Overridden methods are bounded using static binding
b. Static binding occurs at compile time and dynamic binding occurs at runtime
c. Private, static, and final methods and variables use static binding and are bounded by compiler
d. Virtual methods are bounded at compile time based upon the runtime object
Explanation: Statements b (static binding at compile time, dynamic at runtime) and c (private/static/final use static binding) are true. Overridden methods use dynamic binding.
3. Match the following inheritance type with the corresponding description:
Inheritance TypeDescription
a. Hierarchical1. A child class derives from more than one parent class
b. Single2. A parent class has more than one child classes at different levels
c. Multiple3. A child class derives from a parent that itself is a child of another class
d. Multilevel4. A child class inherits from one and only one parent class
Explanation: Hierarchical (a-2), Single (b-4), Multiple (c-1), Multilevel (d-3).
4. Consider following code: class Furniture { String ID; float price; public Furniture(String ID, float price){ this.ID = ID; this.price = price; } public void displayDetails() { System.out.println("ID: "+ID); System.out.println("Price: "+price); } } public class Table extends Furniture { String type; public Table(String ID, float price, String type) { super(ID,price); this.type = type; } public void displayDetails(){ super.displayDetails(); System.out.println("Type: "+type); } public static void main(String[] args){ Furniture obj = new Table("F001 ", 2000F, "Wooden "); obj.displayDetails(); } } What will be the output of the code?
Explanation: Polymorphism invokes Table's displayDetails(), which calls super.displayDetails() (prints ID and Price) and then prints Type: Wooden.
5. Consider following code: Car objCar = new Car(); Vehicle objVehicle = objCar; Which concept of object-oriented programming is used in the code?
Explanation: Assigning a subclass reference (Car) to a superclass reference variable (Vehicle) is called Upcasting.
6. Consider following code: class Animal { ... } class Herbivore extends Animal { ... } class Deer extends Herbivore { ... } Which type of inheritance is used in the code?
Explanation: A class extending a derived class (`Animal` → `Herbivore` → `Deer`) forms a Multilevel inheritance chain.

Session 8: Interfaces and Nested Classes (8.4 Check Your Progress)

1. An interface is saved with a _______ extension.
Explanation: Source files declaring an interface are saved with the standard .java file extension.
2. Which of the following statements about an interface are true?
a. An interface can contain multiple methods
b. An interface can be instantiated
c. All the methods of an interface are implicitly abstract
d. An interface can have constructors
Explanation: Statements a (can contain multiple methods) and c (methods are implicitly abstract) are true. Interfaces cannot be instantiated directly and cannot have constructors.
3. Match following description with the corresponding nested class type:
DescriptionNested Class Type
a. A non-static inner class declared as a member of the outer class1. Local Inner Class
b. An inner class declared without a name within a code block2. Member Class
c. An inner class defined within a code block such as body of a method3. Static Nested Class
d. Cannot directly refer to instance variables of outer class except through object ref4. Anonymous Class
Explanation: Member Class (a-2), Anonymous Class (b-4), Local Inner Class (c-1), Static Nested Class (d-3).
4. Consider following code: public interface Publisher { public void addContact(); public void getRoyaltyAmt(); } public class Book implements Publisher { String ID; String type; public Book(String ID, String type) { this.ID = ID; this.type = type; } @Override public void addContact() { System.out.println("Storing contact ....."); } @Override public void getRoyaltyAmt() { System.out.println("Royalty amount is $2000"); } public void displayDetails() { System.out.println("Book ID: " + ID); System.out.println("Book Type.: " + type); } public static void main(String[] args) { if (args.length == 2) { Book objBook1 = new Book(args[0], args[1]); objBook1.displayDetails(); objBook1.addContact(); objBook1.getRoyaltyAmt(); } else { System.out.println("Usage: java Book "); } } } What will be the output of the code when user passes 'B001' as the command line argument?
Explanation: Passing only 1 argument makes args.length == 1. Since args.length == 2 evaluates to false, it executes the else block printing: Usage: java Book <ID> <Type>.
5. Identify the correct syntax to implement multiple interfaces in a class.
Explanation: Multiple interfaces implemented by a class are separated by commas: implements A, B.
6. Consider following code: class Bird { public void moveBird() { Object o = new Fly() { public void flightSpeed(int speed) { System.out.println("Flying at "+ speed + "kmph"); } }; } } class Fly { public void flightSpeed(int speed) {} } Which type of nested class is used in the code?
Explanation: new Fly() { ... } instantiates an inline Anonymous inner class extending `Fly`.

b. The exception object holds information about the type of error and state of the program
c. An appropriate exception handler is one that handles all types of exceptions
d. If a handler is not found in the method, the runtime proceeds through the call stack...
Explanation: Statements a (reasons for exception) and b (exception object holds state & type info) are true.

b. IllegalArgumentException2. Occurs upon attempt to create instance of an abstract class

Session 10: Date and Time API (10.9 Check Your Progress)

1. Which of the following APIs represents a specialized Date-Time API to deal with various time-zones?
Explanation: The Zoned Date-Time API (ZonedDateTime / ZoneId) handles date and time in a specified time-zone.
2. Which of following options does the Instant class represent?
Explanation: An Instant represents an instantaneous point / specific time on the timeline (nanoseconds from 1970-01-01T00:00:00Z epoch).
3. Which of these two methods can be used to perform Duration calculations?
Explanation: Methods like plusNanos() and minusNanos() perform duration addition/subtraction calculations on Duration objects.
4. Which of the following are three types of offsets?
Explanation: Time-zone offset transitions during Daylight Saving Time are categorized into Normal, Gap (spring forward), and Overlap (fall back).
5. Which among the following methods comes under the class java.time.temporal.TemporalAdjusters?
Explanation: TemporalAdjusters provides helper adjusters like firstDayOfMonth(), lastDayOfMonth(), and adjustment transformers.

Session 11: Additional Features of Java (11.4 Check Your Progress)

1. What is the purpose of the @Override annotation in Java?
Explanation: @Override documents intent, enables compile-time safety check for correct method signatures, and enhances readability.
2. Which of these features were introduced in recent versions of Java?
Explanation: Sealed Classes were introduced in recent Java versions (Java 15/17) to restrict which classes can extend or implement them.
3. What is the advantage of using generics in Java?
Explanation: Generics (e.g. List<String>) provide compile-time type safety and eliminate repetitive explicit type casting.
4. What is a stream in Java?
Explanation: A Java Stream (java.util.stream) is a sequence of data elements supporting functional pipelines like filter(), map(), and collect().
5. What is a module in Java?
Explanation: A Java 9+ Module (JPMS) is a self-contained unit specifying `requires` dependencies and `exports` packages via `module-info.java`.

Session 12: JDK 20 New Features and Functionalities (12.2 Check Your Progress)

1. Which of the following statements is true for virtual threads?
Explanation: Virtual Threads (Project Loom) are lightweight JVM-managed user threads that run on shallow stacks and suspend/resume efficiently.
2. What is the main purpose of Vector API in Java 20?
Explanation: The Vector API expresses vector calculations compiled into SIMD vector instructions on supported CPU architectures.
3. What is the main class of structured concurrency API in Java 20?
Explanation: StructuredTaskScope manages concurrent subtasks as a single unit of work.
4. What is the main difference between scoped values and thread-local variables in Java 20?
Explanation: Scoped Values are immutable, bound to a bounded dynamic scope, and automatically cleaned up when the scope exits.
5. Which of the following statements is false about record patterns in Java 20?
Explanation: Statement (D) is FALSE because record patterns do not match `null` values (matching against null evaluates to false or throws NPE in switch).
