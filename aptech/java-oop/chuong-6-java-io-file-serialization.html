CHƯƠNG 6. JAVA I/O STREAMS, THAO TÁC FILE & SERIALIZATION

Byte stream vs Character stream, BufferedReader/Writer, Serialization và từ khóa transient.

6.1 Luồng Vào/Ra Byte Stream vs Character Stream

  • Byte Streams (`InputStream`, `OutputStream`): Đọc ghi dữ liệu nhị phân 8-bit (file ảnh, video, audio, file nén zip). Các lớp: FileInputStream, FileOutputStream.
  • Character Streams (`Reader`, `Writer`): Đọc ghi văn bản định dạng Unicode 16-bit (file `.txt`, `.json`, `.csv`). Các lớp: FileReader, FileWriter, BufferedReader, BufferedWriter.
import java.io.*; public class FileIODemo { public static void main(String[] args) { // Đọc file văn bản dòng theo dòng bằng BufferedReader try (BufferedReader br = new BufferedReader(new FileReader("data.txt"))) { String line; while ((line = br.readLine()) != null) { System.out.println(line); } } catch (IOException e) { e.printStackTrace(); } } }

6.2 Kỹ Thuật Tuần Tự Hóa Đối Tượng (Serialization)

Serialization là quá trình chuyển đổi trạng thái của một đối tượng thành một luồng byte để lưu trữ vào file hoặc truyền qua mạng. Lớp muốn tuần tự hóa bắt buộc phải triển khai giao diện java.io.Serializable.

Từ khóa `transient`: Dùng để đánh dấu các thuộc tính nhạy cảm (như password, credit card) không được phép tuần tự hóa vào file.
