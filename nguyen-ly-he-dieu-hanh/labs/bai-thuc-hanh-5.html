BÀI THỰC HÀNH BUỔI 5 - QUẢN LÝ VÀO/RA, TẬP TIN VÀ ĐỔI HƯỚNG

Nội dung thực hành: Cơ trúc cây hệ thống tập tin Unix/Linux, các loại tập tin, đường dẫn tuyệt đối/tương đối, phân quyền file/thư mục (chmod, chown, chgrp), quản lý user/group (/etc/passwd, /etc/group), đổi hướng các luồng vào/ra chuẩn (stdin, stdout, stderr), đường ống (Pipe |), lệnh tee và lời giải chi tiết 18 bài tập thực hành. (Theo Tài liệu Thực hành HĐH - ThS. Phan Thượng Cang & ThS. Bùi Quốc Thái, Bộ môn HTMT&TT • ĐHCT).

1. Tổ Chức Hệ Thống Tập Tin Unix/Linux

1.1 3 Kiểu tập tin cơ bản

  • Tập tin bình thường (Regular file): Chứa dữ liệu dạng văn bản (ASCII/text) hoặc mã nhị phân (binary). Ký hiệu dạng -.
  • Tập tin thư mục (Directory file): Chứa danh sách các tên file/thư mục con. Ký hiệu dạng d.
  • Tập tin đặc biệt (Special/Device file): Đại diện cho các thiết bị phần cứng ngoại vi hoặc cơ chế truyền tin (bàn phím input, màn hình/máy in output). Ký hiệu dạng c (character) hoặc b (block).

1.2 Cấu trúc Cây hệ thống tập tin Linux

Các tập tin của Unix được tổ chức theo cấu trúc cây phân cấp bắt đầu từ thư mục gốc (Root - /):

Thư mục chuẩn Chức năng & Nội dung lưu trữ
/ Thư mục gốc (Root directory), chứa tất cả các thư mục khác
/bin Chứa các file thực thi nhị phân (binary commands) cần cho khởi động & chế độ đơn dùng (ls, cp, cat, bash...)
/boot Chứa Kernel image, grub và các file cấu hình khởi động hệ thống
/dev Chứa các file thiết bị phần cứng đặc biệt (sda, null, tty, zero...)
/etc Chứa tất cả các file cấu hình hệ thống (passwd, group, shadow, login.defs...)
/home Chứa thư mục cá nhân (home directory) của các người dùng thường
/lib Chứa các thư viện chia sẻ (shared libraries) cần cho các lệnh trong /bin và /sbin
/mnt Điểm gá lắp (mount point) tạm thời cho các thiết bị lưu trữ (USB, HDD ngoài...)
/proc Hệ thống tập tin ảo (virtual filesystem) lưu trữ thông tin về Kernel và tiến trình đang chạy
/sbin Chứa các lệnh thực thi dành riêng cho quản trị hệ thống (System Binaries: fdisk, reboot, ifconfig...)
/tmp Chứa các tập tin tạm thời do hệ thống hoặc ứng dụng tạo ra
/usr Chứa các chương trình, thư viện, tài liệu dùng chung cho người dùng (usr/bin, usr/lib, usr/share...)
/var Chứa dữ liệu thường xuyên biến đổi (system logs /var/log, mail /var/spool/mail, print spool...)

2. Đường Dẫn & Thao Tác Di Chuyển Thư Mục

2.1 Đường dẫn tuyệt đối vs Tương đối

  • Đường dẫn tuyệt đối (Absolute Path): Chỉ rõ vị trí bắt đầu từ gốc / (ví dụ: /home/user1/notes). Luôn bắt đầu bằng /.
  • Đường dẫn tương đối (Relative Path): Bắt đầu tính từ thư mục làm việc hiện hành (ví dụ đứng tại /home thì gõ user1/notes).

Ký hiệu đặc biệt trong đường dẫn:

  • . : Thư mục hiện hành (current directory).
  • .. : Thư mục cha (parent directory).
  • ~ : Thư mục home của người dùng đang đăng nhập (Home directory).

2.2 Các lệnh di chuyển thư mục:

$ pwd /home/user1 $ cd /usr/bin $ pwd /usr/bin $ cd .. $ pwd /usr $ cd $ pwd /home/user1

3. Quyền Truy Cập & Quản Lý Người Dùng / Nhóm

3.1 Phân tích chi tiết một mục từ `ls -l`

-rwxrw-r-- 1 xyz staff 12 Mar 7 12:35 test
  • - : Ký tự đầu tiên cho biết đây là file thường (nếu d là thư mục).
  • rwx : Quyền của Owner (xyz) → Đọc (Read), Ghi (Write), Thực thi (Execute).
  • rw- : Quyền của Group (staff) → Đọc, Ghi, không được Thực thi.
  • r-- : Quyền của Other (người khác) → Chỉ được Đọc.
  • 1 : Số liên kết cứng (Hard links) trỏ đến file.
  • xyz : Tên tài khoản sở hữu (Owner).
  • staff : Tên nhóm sở hữu (Group).
  • 12 : Kích thước tập tin (bytes).
  • Mar 7 12:35 : Thời điểm chỉnh sửa gần nhất.
  • test : Tên tập tin.

3.2 Quản lý Người dùng & Nhóm hệ thống

  • Thông tin User: Lưu tại file /etc/passwd (username, password, uid, gid, comment, home dir, default shell). Lệnh quản trị: useradd.
  • Thông tin Group: Lưu tại file /etc/group (groupname, password, gid, members). Lệnh quản trị: groupadd.

Ý nghĩa quyền đối với Thư mục:

Quyền Đối với Tập tin (File) Đối với Thư mục (Directory)
r (Read) Đọc nội dung tập tin Xem/liệt kê danh sách các file trong thư mục (lệnh ls)
w (Write) Sửa đổi, ghi đè nội dung tập tin Tạo mới, đổi tên hoặc xóa các tập tin bên trong thư mục
x (Execute) Thực thi tập tin như chương trình Đi qua/truy cập vào thư mục (lệnh cd)

4. Vào/Ra Chuẩn & Đổi Hướng (I/O Redirection & Pipes)

4.1 Các luồng Vào/Ra chuẩn (Standard I/O Streams)

  • stdin (Standard Input - Descriptor 0): Đầu vào chuẩn (Mặc định: Bàn phím).
  • stdout (Standard Output - Descriptor 1): Đầu ra chuẩn (Mặc định: Màn hình Console).
  • stderr (Standard Error - Descriptor 2): Đầu ra lỗi chuẩn (Mặc định: Màn hình Console).

4.2 Cú pháp Đổi hướng & Đường ống (Pipes)

Cú pháp Đổi hướng Ý nghĩa & Chức năng Ví dụ câu lệnh
lệnh > file Đổi hướng stdout vào file (Ghi đè - Overwrite) ls /bin > file1
lệnh >> file Đổi hướng stdout vào file (Ghi nối tiếp - Append) ls /bin >> file1
lệnh 2> file Đổi hướng lỗi stderr vào file (Ghi đè) ls /root 2> err.log
lệnh > file 2>&1 Đổi hướng cả stdout và stderr vào cùng 1 file ls /root > out.log 2>&1
lệnh 2> /dev/null Hủy bỏ toàn bộ thông báo lỗi ra thiết bị null find / -name "*.c" 2> /dev/null
lệnh < file Đổi hướng đầu vào stdin lấy dữ liệu từ file wc -l < file1
lệnh << STRING ... STRING Here-Document: Đọc dữ liệu đến khi gặp nhãn STRING cat > file1 << OK ... OK
lệnh1 | lệnh2 Đường ống (Pipe): Lấy stdout của lệnh1 làm stdin của lệnh2 ps -ef | grep bash
lệnh | tee file Đổi hướng kép: Vừa in ra màn hình vừa ghi ra file ps -ef | tee file_ps | grep root

BÀI TẬP THỰC HÀNH & HƯỚNG DẪN LỜI GIẢI CHI TIẾT (BÀI 1 → 18)

Bài 1: Thư mục Home và Quyền trên Thư mục Home
$ cd ~ && pwd /home/user1 $ ls -ld /home/user1 drwxr-xr-x 5 user1 user1 4096 Mar 7 10:00 /home/user1

Mô tả: Thư mục Home của user1 có đường dẫn /home/user1. Quyền drwxr-xr-x cho phép Owner (user1) có toàn quyền đọc/ghi/truy cập (`rwx`), Group và Other có quyền đọc và truy cập (`r-x`).

Bài 2: Liệt kê các thư mục dưới gốc `/`
$ ls -l /

Hiển thị các thư mục chuẩn bin, boot, dev, etc, home, lib, mnt, proc, sbin, tmp, usr, var với quyền sở hữu mặc định thuộc về người dùng root.

Bài 3: Giải thích chi tiết mục từ thư mục
drwxr-xr-- 2 abc users 1024 Mar 7 12:35 ddd
  • d: Loại tập tin là **Thư mục (Directory)**.
  • rwx: Chủ sở hữu (Owner abc) có quyền đọc, ghi, và truy cập thư mục.
  • r-x: Nhóm sở hữu (Group users) có quyền đọc danh sách và truy cập, không được sửa/tạo/xóa file trong thư mục.
  • r--: Những người dùng khác (Other) chỉ có quyền đọc tên thư mục.
  • 2: Số liên kết (Hard links).
  • abc: Tên tài khoản Owner sở hữu.
  • users: Tên Group sở hữu.
  • 1024: Kích thước thư mục (1024 bytes).
  • Mar 7 12:35: Thời điểm chỉnh sửa gần nhất.
  • ddd: Tên thư mục.
Bài 4: Thư mục chứa các file cấu hình hệ thống

Thư mục /etc chứa tất cả các tập tin cấu hình của hệ thống Linux.

Bài 5: Hai thư mục chứa tập tin thư viện lệnh

Hai thư mục chứa các tập tin thư viện lệnh là /lib và /usr/lib.

Bài 6: Phân biệt thư mục `/` và thư mục `/root`
  • / (Thư mục Gốc - Root directory): Là thư mục cao nhất trong hệ thống tập tin Linux, chứa tất cả các thư mục con khác.
  • /root: Là thư mục Home riêng cá nhân của tài khoản quản trị tối cao (Superuser root).
Bài 7: Xác định tên thư mục hiện hành qua chuỗi lệnh `cd`
  1. cd ~ → Về thư mục Home (ví dụ: /home/user1).
  2. cd . → Vẫn ở thư mục hiện tại (/home/user1).
  3. cd .. → Lên thư mục cha (/home).
  4. cd user1 → Chuyển vào thư mục tài khoản login (/home/user1).
Bài 8: Di chuyển thư mục từ `/var/spool`

Giả sử đang ở /var/spool:

  • Thực hiện cd mail → Thư mục mới là /var/spool/mail.
  • Sau đó thực hiện cd ../../spool/mail → Thư mục mới là /spool/mail.
Bài 9: Các câu hỏi thao tác thư mục trong `/var` và Home
  1. cd /var && ls -l | grep "^d" | wc -l → Đếm số thư mục con dưới /var.
  2. ls /sbin → Xem bình thường nếu có quyền đọc, hoặc báo Permission denied nếu bị cấm.
  3. mkdir /var/userxxx → Báo lỗi mkdir: cannot create directory '/var/userxxx': Permission denied vì user thường không có quyền ghi vào /var.
  4. cd ~ && mkdir ddddd → Tạo thành công vì user có toàn quyền ghi trong thư mục Home của mình.
  5. cd ddddd && echo "This is a message" > fffff && cat fffff → Tạo thành công file fffff chứa câu văn bản.
  6. Đứng tại /home/user1/ddddd gõ rmdir /home/user1/ddddd → Báo lỗi rmdir: failed to remove 'ddddd': Directory not empty (thư mục không rỗng) và không thể xóa thư mục khi đang đứng bên trong.
Bài 10: Liệt kê các tập tin ẩn trong thư mục Home
$ cd ~ && ls -a . .. .bash_history .bash_logout .bash_profile .bashrc

Tập tin ẩn: Là các tập tin có tên bắt đầu bằng dấu chấm . (ví dụ: .bashrc, .bash_profile).

Bài 11: Hiển thị các dòng cuối tập tin với lệnh `tail`
# 1. 4 dòng cuối /etc/passwd: $ tail -n 4 /etc/passwd # 2. 6 dòng cuối /etc/group: $ tail -n 6 /etc/group # 3. 8 dòng cuối /etc/login.defs: $ tail -n 8 /etc/login.defs # 4. 20 dòng cuối /etc/login.defs: $ tail -n 20 /etc/login.defs

Nhận xét: Tùy chọn -n K cho phép trích xuất chính xác $K$ dòng cuối cùng của tập tin văn bản.

Bài 12: 12 Thao tác quản lý tập tin & thư mục nâng cao
# 1. Tạo 7 file trong Home: touch one two three four five r1 r2 && ls -l # 2. Thử tạo 7 file trong /var (bị chối quyền Permission denied do không có quyền write): touch /var/one # 3. Sao chép .bash_profile thành bprofile: cp ~/.bash_profile bprofile && ls -l bprofile # 4. Tạo liên kết cứng / mềm lbprofile trỏ đến bprofile: ln -s bprofile lbprofile && ls -l lbprofile # 5. Chép 7 file sang /tmp: cp one two three four five r1 r2 /tmp/ && ls -l /tmp # 6. Chép 7 file sang /root (bị Permission denied do /root bảo vệ chỉ dành cho root): cp one two three four five r1 r2 /root/ # 7. Chép /etc/passwd về Home: cp /etc/passwd ~/passwd && ls -l ~/passwd /etc/passwd # File passwd ở Home thuộc sở hữu người dùng hiện tại nên người dùng có quyền sửa/xóa! # 8. Tạo thư mục dir1, dir2 và thư mục con dir2a: mkdir -p dir1 dir2/dir2a && ls -ld dir1 dir2 dir2/dir2a # 9. Di chuyển file one vào dir1: mv one dir1/ && ls -l dir1/ # 10. Chuyển tất cả file bắt đầu bằng 'f' vào dir2: mv f* dir2/ && ls -l dir2/ # 11. Chuyển r1 và r2 vào dir2/dir2a không dùng wildcard (*,?): mv r1 r2 dir2/dir2a/ && ls -l dir2/dir2a/ # 12. Xóa thư mục dir2a: rm -rf dir2/dir2a
Bài 13: Quản lý Quyền thực thi và Phân quyền file (12 câu nhỏ)
# 1 & 2. Tạo script hello và reply: echo 'echo "Hello"' > hello echo 'echo "How are you ?"' >> hello echo 'echo "Hello"' > reply echo 'echo "Fine. And you ?"' >> reply # 3 & 4. Xem quyền và chạy thử: ls -l hello reply ./hello # Báo lỗi: Permission denied vì chưa có quyền thực thi (x)! # 5. Cấp quyền thực thi và chạy lại: chmod +x hello reply ./hello ./reply # 6. Bỏ quyền group và other: chmod go-rwx hello reply # 7. Cho phép group đọc và chạy: chmod g+rx hello reply # 8 & 9. Thay đổi người sở hữu (cần sudo): # sudo chown root hello # 10, 11 & 12. Điều kiện để user khác chạy file hello1: # Thư mục chứa file phải có quyền +x cho other/group, và file hello1 phải có quyền +r+x. # Nếu đổi tên hello1 thành rm và chạy lệnh rm -> script hello1 sẽ được gọi thay vì lệnh rm hệ thống nếu đường dẫn PATH ưu tiên thư mục hiện tại.
Bài 14: Phân biệt các lệnh xem tập tin (cat, head, tail, more, less)
Câu lệnh Đặc điểm & Chức năng Ví dụ sử dụng
cat In toàn bộ nội dung file ra màn hình một lượt cat /etc/passwd
head Chỉ in $N$ dòng đầu tiên của file (mặc định 10 dòng) head -n 5 /etc/passwd
tail Chỉ in $N$ dòng cuối cùng của file (mặc định 10 dòng) tail -n 5 /etc/passwd
more Xem file phân trang theo chiều cuộn xuống (Space để qua trang) more /etc/passwd
less Xem file phân trang nâng cao (cho phép cuộn lên/xuống, tìm kiếm /) less /etc/passwd
Bài 15: Các ví dụ ứng dụng lệnh `find`
# 1. Tìm tất cả các file có đuôi .html: find / -name "*.html" 2>/dev/null # 2. Tìm tất cả các file thuộc sở hữu của root: find /home -user root # 3. Tìm thư mục có tên lib trong /usr: find /usr -type d -name "lib" # 4. Lệnh find phát sinh lỗi Permission denied (khi tìm trong thư mục bảo vệ của hệ thống): find /root -name "*.txt" # Giải thích: Người dùng thường không có quyền đọc (r) hoặc truy cập (x) vào /root! # 5. Tìm tất cả file bị sửa đổi trong vòng 24 giờ qua: find ~ -mtime -1 # 6. Liệt kê tất cả thư mục rỗng: find ~ -type d -empty
Bài 16: Các ví dụ ứng dụng lệnh `grep`
# 1. Hiển thị số dòng và các dòng chứa chuỗi 'root' trong /etc/passwd: grep -n "root" /etc/passwd # 2. Hiển thị các dòng KHÔNG chứa chuỗi 'root' trong /etc/passwd: grep -v "root" /etc/passwd # 3. Liệt kê các file trong /etc/ chứa chuỗi 'echo': grep -l "echo" /etc/* 2>/dev/null # 4. Hiển thị các dòng trong /etc/login.defs KHÔNG phải dòng chú thích (#): grep -v "^#" /etc/login.defs | grep -v "^$" # 5. Hiển thị danh sách user có shell đăng nhập là /bin/bash: grep "/bin/bash" /etc/passwd | cut -d: -f1
Bài 17: Thực hành Đổi Hướng I/O & Đường Ống Pipe (9 câu)
# 1. Lưu danh sách thư mục con vào file one: ls -l | grep "^d" > one && cat one # 2. Hiển thị danh sách người dùng đăng nhập và lưu vào users: who | tee users # 3. Lưu danh sách tiến trình vào cuối file users: ps -ef >> users # 4. Xem nội dung /etc theo từng trang: ls -l /etc | more # 5. Đếm số byte, số từ và số dòng trong /etc/passwd: wc /etc/passwd # 6. Sắp xếp nội dung /etc/group: sort /etc/group # 7. Hiển thị nội dung /var/spool/mail sắp xếp theo kích thước: ls -lS /var/spool/mail 2>/dev/null # 8. Liệt kê các dịch vụ dùng giao thức tcp trong /etc/services: grep "tcp" /etc/services | more # 9. Nhập danh sách họ tên sinh viên từ bàn phím và lưu sắp xếp vào file students: sort > students <
Bài 18: Giải thích Pipeline kết quả lệnh `sort`, `grep`, `wc`, `head`

Tạo file commands trong thư mục Home:

cal /usr/bin 9416 date /bin 2860 who /usr/bin 8692 cat /bin 18056 lpd /usr/sbin 42012
  1. sort -r commands | head -1 → Sắp xếp các dòng trong file commands theo thứ tự ngược bảng chữ cái (giảm dần) và lấy dòng đầu tiên lớn nhất (dòng who...).
  2. grep ^c commands | wc -l → Lọc các dòng bắt đầu bằng chữ 'c' (gồm cal và cat), sau đó đếm số dòng thu được $\rightarrow$ Kết quả in ra là 2.
  3. grep at commands | sort → Lọc các dòng chứa chuỗi 'at' (gồm date và cat), sau đó sắp xếp theo thứ tự bảng chữ cái $\rightarrow$ In ra dòng cat trước, date sau.
