Thiết kế Cơ sở Dữ liệu PostgreSQL & Redis Cache

Một thiết kế CSDL quan hệ chuẩn (Normalized Relational Schema) là yếu tố quyết định sự thành bại của đề tài niên luận. Dưới đây là lược đồ các bảng cốt lõi:

PostgreSQL Schema DDl (Core Tables) 
-- Bảng Người dùng
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    role VARCHAR(20) DEFAULT 'STUDENT', -- STUDENT, INSTRUCTOR, ADMIN
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Bảng Khóa học
CREATE TABLE courses (
    id SERIAL PRIMARY KEY,
    instructor_id INT REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    category_id INT,
    price DECIMAL(10, 2) DEFAULT 0.00,
    is_published BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Bảng Tương tác Người dùng - Khóa học (Phục vụ ML Recommendation)
CREATE TABLE interactions (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    course_id INT REFERENCES courses(id) ON DELETE CASCADE,
    interaction_type VARCHAR(30) NOT NULL, -- 'VIEW', 'LIKE', 'ENROLL', 'RATE'
    rating NUMERIC(2, 1) CHECK (rating >= 1.0 AND rating <= 5.0),
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Chiến lược Caching với Redis

Hệ thống sử dụng **Redis** để lưu trữ bộ nhớ tạm thời với 3 mục đích chính:

  • User Session Cache: Lưu token xác thực và thông tin profile của người dùng active.
  • Recommendation Top-K Cache: Kết quả tính toán gợi ý bởi Python Engine được cache trong 1 giờ (Key format: user:recommendations:{user_id}).
  • API Rate Limiting: Giới hạn số lượng request tối đa 100 req/phút để bảo vệ hệ thống khỏi các đợt tấn công từ chối dịch vụ.
Phần 4

Xây dựng Backend Server với Node.js & Express.js

Backend được thiết kế theo mô hình **Modular Architecture**, trong đó từng miền chức năng (Domain) được cô lập sạch sẽ thành các Controller, Service và Repository.

Node.js Express Controller Example (Course Recommendation Fetch) 
const express = require('express');
const router = express.Router();
const redisClient = require('../config/redis');
const axios = require('axios');
const authMiddleware = require('../middlewares/auth');

// GET /api/courses/recommendations
router.get('/recommendations', authMiddleware, async (req, res, next) => {
  try {
    const userId = req.user.id;
    const cacheKey = `user:recommendations:${userId}`;

    // 1. Kiểm tra cache Redis trước
    const cachedData = await redisClient.get(cacheKey);
    if (cachedData) {
      return res.json({ success: true, source: 'cache', data: JSON.parse(cachedData) });
    }

    // 2. Gọi microservice Python Recommendation Engine nếu miss cache
    const response = await axios.post('http://recommendation-engine:8000/api/recommend', {
      user_id: userId,
      top_k: 6
    });

    const recommendedCourses = response.data.courses;

    // 3. Cache kết quả trong 3600 giây (1 giờ)
    await redisClient.setEx(cacheKey, 3600, JSON.stringify(recommendedCourses));

    return res.json({ success: true, source: 'engine', data: recommendedCourses });
  } catch (error) {
    next(error);
  }
});

module.exports = router;
Phần 5

Xây dựng Recommendation Engine (Python & Machine Learning)

Đây là trái tim của đề tài niên luận. Hệ thống sử dụng kỹ thuật **Hybrid Recommendation (Gợi ý lai)** kết hợp hai trường phái phổ biến: **Content-Based Filtering** và **Collaborative Filtering**.

1. Content-Based Filtering (Lọc dựa trên nội dung)

Sử dụng thuật toán **TF-IDF (Term Frequency - Inverse Document Frequency)** để mã hóa văn bản mô tả khóa học thành các vector đặc trưng, sau đó dùng **Cosine Similarity** để đo độ tương đồng giữa các khóa học với sở thích sinh viên:

$$\text{TF}(t, d) = \frac{f_{t,d}}{\sum_{t' \in d} f_{t',d}}, \quad \text{IDF}(t, D) = \ln\left(\frac{|D|}{|\{d \in D : t \in d\}|}\right)$$ $$\text{Cosine Similarity}(\mathbf{A}, \mathbf{B}) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \sqrt{\sum_{i=1}^{n} B_i^2}}$$

2. Collaborative Filtering (Lọc cộng tác User-Based / Item-Based)

Sử dụng chỉ số hệ số tương quan **Pearson Correlation** để đo độ tương đồng hành vi giữa các người dùng có cùng gu học tập:

$$r_{u, v} = \frac{\sum_{i \in I_{uv}} (R_{u,i} - \bar{R}_u)(R_{v,i} - \bar{R}_v)}{\sqrt{\sum_{i \in I_{uv}} (R_{u,i} - \bar{R}_u)^2} \sqrt{\sum_{i \in I_{uv}} (R_{v,i} - \bar{R}_v)^2}}$$

3. Hybrid Recommendation & Offline Evaluation

Điểm số gợi ý cuối cùng là tổng có trọng số ($\alpha = 0.4$, $1-\alpha = 0.6$):

$$\text{Score}_{\text{hybrid}}(u, i) = \alpha \cdot \text{Score}_{\text{CB}}(u, i) + (1 - \alpha) \cdot \text{Score}_{\text{CF}}(u, i)$$
Python Scikit-Learn Hybrid Recommendation Implementation 
import numpy as np
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

class HybridRecommender:
    def __init__(self, alpha=0.4):
        self.alpha = alpha
        self.tfidf = TfidfVectorizer(stop_words='english')
        
    def fit_content_based(self, course_df):
        # Kết hợp tiêu đề và mô tả khóa học
        course_df['features'] = course_df['title'] + " " + course_df['description']
        self.tfidf_matrix = self.tfidf.fit_transform(course_df['features'])
        self.cb_sim_matrix = cosine_similarity(self.tfidf_matrix, self.tfidf_matrix)
        self.course_df = course_df
        
    def predict_hybrid(self, user_profile_vector, cf_scores_array):
        # 1. Tính toán điểm Content-Based
        cb_scores = cosine_similarity(user_profile_vector, self.tfidf_matrix).flatten()
        
        # 2. Chuẩn hóa điểm Min-Max về khoảng [0, 1]
        cb_norm = (cb_scores - np.min(cb_scores)) / (np.max(cb_scores) - np.min(cb_scores) + 1e-9)
        cf_norm = (cf_scores_array - np.min(cf_scores_array)) / (np.max(cf_scores_array) - np.min(cf_scores_array) + 1e-9)
        
        # 3. Kết hợp có trọng số Weighted Sum
        hybrid_scores = self.alpha * cb_norm + (1 - self.alpha) * cf_norm
        
        # Lấy Top-K index có điểm số cao nhất
        top_k_indices = np.argsort(hybrid_scores)[::-1][:6]
        return self.course_df.iloc[top_k_indices]

Xây dựng Frontend Client (ReactJS & Redux Toolkit)

Frontend được tổ chức giao diện theo component linh hoạt, kết nối trực tiếp đến backend APIs để cập nhật giao diện theo thời gian thực.

React Redux Recommendation Fetch Component 
import React, { useEffect } from 'react';
import { useDispatch, useSelector } from 'react-redux';
import { fetchRecommendedCourses } from '../redux/slices/recommendationSlice';

export const RecommendationFeed = () => {
  const dispatch = useDispatch();
  const { courses, loading } = useSelector((state) => state.recommendation);

  useEffect(() => {
    dispatch(fetchRecommendedCourses());
  }, [dispatch]);

  if (loading) return <div className="animate-pulse">Đang tính toán khóa học gợi ý...</div>;

  return (
    <section className="my-8">
      <h2 className="text-2xl font-bold mb-4 text-blue-600">✨ Đề Xuất Dành Riêng Cho Bạn</h2>
      <div className="grid grid-cols-1 md:grid-cols-3 gap-6">
        {courses.map((course) => (
          <div key={course.id} className="border rounded-lg p-4 shadow-sm hover:shadow-md transition">
            <h3 className="font-semibold text-lg">{course.title}</h3>
            <p className="text-sm text-gray-600 line-clamp-2 mt-2">{course.description}</p>
            <div className="mt-4 flex justify-between items-center">
              <span className="text-xs font-medium px-2 py-1 bg-green-100 text-green-800 rounded">
                Độ khớp: {(course.score * 100).toFixed(0)}%
              </span>
              <a href={`/courses/${course.id}`} className="text-blue-500 hover:underline text-sm font-semibold">
                Xem ngay →
              </a>
            </div>
          </div>
        ))}
      </div>
    </section>
  );
};
