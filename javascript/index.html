01

Introduction (Giới thiệu JavaScript)

JavaScript (JS) là ngôn ngữ lập trình kịch bản đa mô hình (multi-paradigm), thông dịch (interpreted) hoặc biên dịch Just-In-Time (JIT), đóng vai trò là trụ cột cốt lõi của phát triển Web hiện đại bên cạnh HTML và CSS.

💡 Cơ chế hoạt động của JavaScript Engine

Trình duyệt sử dụng các engine siêu tốc (như V8 Engine trên Chrome/Node.js, SpiderMonkey trên Firefox) để parse mã nguồn JS thành AST (Abstract Syntax Tree), sau đó JIT Compiler chuyển đổi trực tiếp thành mã máy (Machine Code) để thực thi với hiệu năng tối ưu.

Cách nhúng JavaScript vào HTML

Bạn có thể chèn JS trực tiếp bằng thẻ <script> hoặc liên kết tệp tin .js bên ngoài với thuộc tính async hoặc defer:

HTML / JavaScript Integration 
<!-- Nhúng file bên ngoài với defer (Khuyên dùng để tối ưu nạp DOM) -->
<script src="app.js" defer></script>

<!-- Code inline trực tiếp -->
<script>
  console.log("Xin chào từ StudyHub JS Guide!");
</script>
02

Syntax (Cú pháp cơ bản & Quy tắc)

JavaScript có cú pháp ảnh hưởng lớn từ C/C++ và Java. Mã JS bao gồm các câu lệnh (statements), biến, toán tử, khối lệnh nằm trong cặp dấu ngoặc nhọn { }.

Các quy tắc cú pháp quan trọng:

  • Case-sensitivity: JS phân biệt rõ ràng chữ hoa và chữ thường (ví dụ: myVar và myvar là 2 biến hoàn toàn khác nhau).
  • CamelCase Naming: Quy chuẩn đặt tên biến/hàm trong JS là camelCase (ví dụ: studentName, calculateTotal).
  • Semicolons (Dấu ;): Mặc dù JS có cơ chế ASI (Automatic Semicolon Insertion), viết dấu chấm phẩy ; ở cuối câu lệnh giúp tránh các lỗi không mong muốn.
  • Strict Mode: Sử dụng dòng đầu tiên 'use strict'; để bắt lỗi cú pháp nghiêm ngặt, ngăn chặn việc dùng biến chưa khai báo.
Syntax Demo 
'use strict'; // Kích hoạt chế độ nghiêm ngặt

// Khai báo biến chuẩn camelCase
let courseTitle = "JavaScript Complete Guide";
let lessonCount = 20;

/* Comment nhiều dòng:
   Hàm hiển thị thông tin học phần */
function showInfo() {
  console.log(courseTitle + " bao gồm " + lessonCount + " bài học.");
}

showInfo();

Variables (Khai báo biến: var, let & const)

JavaScript cung cấp 3 từ khóa để khai báo biến: var (truyền thống), let và const (ra mắt từ ES6).

Từ khóa Phạm vi (Scope) Hoisting Khai báo lại Gán lại giá trị
var Function Scope Có (khởi tạo undefined) Có Có
let Block Scope { } Có (vào TDZ -Temporal Dead Zone) Không Có
const Block Scope { } Có (vào TDZ) Không Không (Hằng số)
Variables Usage 
const PI = 3.14159; // Không thể gán lại giá trị mới
let score = 100;    // Biến thay đổi được giá trị
score += 50;

if (true) {
  let blockScoped = "Chỉ tồn tại trong khối if này";
  var functionScoped = "Tồn tại ngoài khối if";
}

console.log("PI:", PI);
console.log("Score:", score);
console.log("var out of block:", functionScoped);

Data Types (Các kiểu dữ liệu trong JS)

Dữ liệu trong JavaScript được chia thành 2 nhóm chính: Primitive Types (Kiểu nguyên thủy) và Reference Types (Kiểu tham chiếu).

Primitive Types: String, Number, Boolean, Null, Undefined, Symbol, BigInt
Reference Types: Object, Array, Function, Date, RegExp
⚠️ Đặc biệt với typeof null và Type Coercion

Trong JS, typeof null trả về "object" (đây là một bug lịch sử của ngôn ngữ). Ngoài ra, JS tự động ép kiểu (Implicit Coercion) khi dùng phép toán cộng chuỗi: "5" + 2 === "52" nhưng "5" - 2 === 3.

Data Types Inspector 
let num = 42;             // Number
let str = "StudyHub";     // String
let isActive = true;      // Boolean
let emptyVal = null;      // Null (Giá trị rỗng cố ý)
let unassigned;           // Undefined (Chưa gán giá trị)
let bigIntNum = 9007199254740991n; // BigInt

console.log(typeof num);       // "number"
console.log(typeof str);       // "string"
console.log(typeof emptyVal);  // "object" (Bug thiết kế JS)
console.log(typeof unassigned);// "undefined"

Operators (Toán tử trong JavaScript)

Các toán tử cho phép thực thi tính toán toán học, so sánh và xử lý logic trên các giá trị dữ liệu.

  • Số học (Arithmetic): +, -, *, /, % (chia lấy dư), ** (lũy thừa).
  • So sánh (Comparison): == (so sánh giá trị ép kiểu), === (so sánh nghiêm ngặt giá trị & kiểu dữ liệu), !=, !==, >, <.
  • Logic: && (AND), || (OR), ! (NOT), ?? (Nullish Coalescing - lấy giá trị khác null/undefined).
  • Optional Chaining (?.): Truy cập an toàn thuộc tính lồng nhau mà không gây lỗi crash.
Operators Example 
// So sánh nghiêm ngặt vs So sánh lỏng lẻo
console.log(5 == "5");  // true (đã bị ép kiểu)
console.log(5 === "5"); // false (khác kiểu dữ liệu)

// Nullish Coalescing (??) & Optional Chaining (?.)
let userConfig = { theme: null };
let selectedTheme = userConfig.theme ?? "dark-mode"; // Lấy "dark-mode" nếu null/undefined

console.log("Theme:", selectedTheme);
console.log("Zipcode:", userConfig?.address?.zipcode); // undefined (không bị crash lỗi)

Conditional Statements (Câu lệnh điều kiện)

Câu lệnh điều kiện điều hướng luôn luồng thực thi của chương trình dựa trên kết quả đúng (true) hoặc sai (false).

Conditionals & Guard Clauses 
let score = 85;

// Cấu trúc if...else if...else
if (score >= 90) {
  console.log("Xuất sắc (A)");
} else if (score >= 80) {
  console.log("Giỏi (B)");
} else {
  console.log("Trung bình / Khá");
}

// Toán tử ba ngôi (Ternary Operator)
let result = score >= 50 ? "Đậu" : "Rớt";
console.log("Kết quả:", result);

// Mẫu thiết kế Guard Clause (Viết code sạch)
function checkAccess(user) {
  if (!user) return "Vui lòng đăng nhập!";
  if (!user.isAdmin) return "Bạn không có quyền truy cập!";
  return "Chào mừng Admin!";
}

Loops (Vòng lặp trong JavaScript)

Vòng lặp giúp lặp đi lặp lại một đoạn mã cho đến khi thỏa mãn điều kiện dừng.

  • for: Vòng lặp cơ bản với biến đếm chỉ số.
  • while: Lặp khi điều kiện còn đúng.
  • do...while: Thực thi khối lệnh ít nhất 1 lần trước khi kiểm tra điều kiện.
  • for...of: Duyệt qua các phần tử của tập hợp lặp được (Array, String, Set, Map).
  • for...in: Duyệt qua các tên thuộc tính (keys) của một Object.
Loops Demo 
const fruits = ["Táo", "Chuối", "Cam"];

// Vòng lặp for...of cho Mảng
for (let fruit of fruits) {
  console.log("Trái cây:", fruit);
}

// Vòng lặp for...in cho Đối tượng
const student = { name: "Trần Vũ Bằng", age: 21, major: "CNTT" };
for (let key in student) {
  console.log(`${key}: ${student[key]}`);
}

Functions (Hàm & Arrow Functions)

Hàm là các khối mã có thể tái sử dụng để thực hiện một tác vụ cụ thể. JS hỗ trợ nhiều cách định nghĩa hàm khác nhau.

Functions & Rest Parameters 
// 1. Function Declaration (Hỗ trợ Hoisting)
function add(a, b) {
  return a + b;
}

// 2. Arrow Function (Cú pháp ES6 ngắn gọn)
const multiply = (a, b = 1) => a * b; // Default Parameter

// 3. Rest Parameters (...args) để nhận vô số tham số
const sumAll = (...numbers) => {
  return numbers.reduce((total, n) => total + n, 0);
};

console.log("Multiply:", multiply(6, 7));
console.log("Sum All:", sumAll(10, 20, 30, 40));

Arrays (Cấu trúc dữ liệu Mảng)

Mảng là danh sách có thứ tự các giá trị, được đánh chỉ số (index) bắt đầu từ 0. Mảng trong JS có thể chứa mixed data types.

Array & Destructuring 
const colors = ["Đỏ", "Xanh lá", "Xanh dương"];

// Truy cập phần tử
console.log(colors[0]); // "Đỏ"

// Phá cấu trúc mảng (Array Destructuring)
const [firstColor, secondColor] = colors;
console.log("First:", firstColor, "Second:", secondColor);

// Toán tử Spread (...) nối mảng
const moreColors = [...colors, "Vàng", "Tím"];
console.log("More colors:", moreColors);

Objects (Đối tượng Key-Value)

Đối tượng (Object) trong JS là tập hợp các cặp khóa - giá trị (key-value pairs), dùng để mô hình hóa thực thể thực tế.

Object Operations 
const course = {
  id: "JS-COMP",
  title: "JavaScript Guide",
  author: "Alvarez Tran",
  lessons: 20,
  getSummary() {
    return `${this.title} bởi ${this.author}`;
  }
};

// Object Destructuring
const { title, author } = course;
console.log("Summary:", course.getSummary());

// Tiện ích Object tích hợp sẵn
console.log("Keys:", Object.keys(course));
console.log("Values:", Object.values(course));

Events (Xử lý sự kiện người dùng)

Events là các hành động tương tác do người dùng thực hiện (click chuột, nhập bàn phím, cuộn trang, submit form) hoặc do hệ thống phát ra.

const btn = document.querySelector("#theme-toggle");

// Lắng nghe sự kiện click
btn?.addEventListener("click", (event) => {
  console.log("Đã click nút đổi giao diện!", event.target);

// Event Delegation (Ủy quyền sự kiện tối ưu bộ nhớ)
document.querySelector(".modules-grid")?.addEventListener("click", (e) => {
  const card = e.target.closest(".mod-card");
  if (card) {
    console.log("Người dùng chọn module:", card.querySelector(".mod-card-header")?.textContent);
  }

Methods (Các phương thức Array & String cốt lõi)

JavaScript cung cấp bộ hàm xử lý dữ liệu mạnh mẽ tích hợp sẵn trong kiểu dữ liệu String và Array.

Phương thức Array nâng cao:

  • map(): Biến đổi từng phần tử và trả về mảng mới.
  • filter(): Lọc các phần tử thỏa điều kiện.
  • reduce(): Tích tụ các phần tử thành một giá trị duy nhất.
  • find() / findIndex(): Tìm phần tử đầu tiên khớp điều kiện.
Array & String Methods 
const numbers = [10, 20, 30, 40, 50];

// map: Nhân đôi từng số
const doubled = numbers.map(n => n * 2);
console.log("Doubled:", doubled);

// filter: Lọc các số >= 30
const filtered = numbers.filter(n => n >= 30);
console.log("Filtered:", filtered);

// reduce: Tính tổng mảng
const sum = numbers.reduce((acc, curr) => acc + curr, 0);
console.log("Sum:", sum);

// String Methods
let text = "   JavaScript Fullstack   ";
console.log(text.trim().toLowerCase().replaceAll("a", "@"));

Scope & Closure (Phạm vi & Closure)

Scope quyết định tính ẩn/hiện và phạm vi truy cập của biến (Global Scope, Function Scope, Block Scope). Closure là một hàm có khả năng "ghi nhớ" và truy cập các biến ở phạm vi bên ngoài (Lexical Scope) ngay cả khi hàm ngoài đã kết thúc thực thi.

Closure Counter Pattern 
function createCounter() {
  let count = 0; // Biến tư nhân (private variable) nhờ Closure

  return {
    increment() {
      count++;
      return count;
    },
    decrement() {
      count--;
      return count;
    },
    getValue() {
      return count;
    }
  };
}

const myCounter = createCounter();
console.log(myCounter.increment()); // 1
console.log(myCounter.increment()); // 2
console.log(myCounter.getValue());   // 2 (Biến count được bảo vệ)
15

Hoisting (Cơ chế Hoisting trong JS)

Hoisting là hành vi của JavaScript Engine đưa các khai báo biến và hàm lên đầu phạm vi chứa nó trong giai đoạn biên dịch (Creation Phase) trước khi thực thi mã.

⚠️ Sự khác biệt Hoisting giữa var vs let/const

var được hoist và khởi tạo ngay giá trị undefined. Ngược lại, let và const cũng được hoist nhưng nằm trong vùng Temporal Dead Zone (TDZ) - truy cập biến trước dòng khai báo sẽ gây lỗi ReferenceError.

Hoisting Test 
// 1. Function Declaration được hoist hoàn toàn
sayHello(); // Hoạt động bình thường!
function sayHello() {
  console.log("Xin chào!");
}

// 2. var được hoist nhưng khởi tạo undefined
console.log(x); // undefined (không bị crash lỗi)
var x = 10;

// 3. let vào Temporal Dead Zone (TDZ)
try {
  console.log(y); // ReferenceError!
  let y = 20;
} catch (e) {
  console.log("Lỗi TDZ:", e.message);
}

Callback là một hàm được truyền dưới dạng đối số vào một hàm khác để được gọi lại thực thi sau khi một tác vụ hoàn tất.

Callback Pattern 
// Hàm nhận callback làm tham số
function processUser(name, callback) {
  console.log("Đang xử lý người dùng: " + name);
  callback(name);
}

processUser("Alvarez", function(userName) {
  console.log("Xử lý hoàn tất cho: " + userName);
});

Promises (Xử lý bất đồng bộ chuẩn xác)

Promise là đối tượng đại diện cho kết quả hoàn thành hoặc thất bại của một tác vụ bất đồng bộ trong tương lai, giải quyết hoàn toàn vấn đề Callback Hell.

Promise States: Pending (Đang chờ) ➔ Fulfilled (Thành công - resolve) OR Rejected (Thất bại - reject)
Promise Example 
const fakeApiFetch = () => {
  return new Promise((resolve, reject) => {
    let success = true;
    setTimeout(() => {
      if (success) resolve({ status: 200, data: "Dữ liệu bài học" });
      else reject("Lỗi kết nối Server!");
    }, 800);
  });
};

// Chaining .then() .catch() .finally()
fakeApiFetch()
  .then(response => {
    console.log("Thành công:", response.data);
    return response.status;
  })
  .then(status => console.log("Status Code:", status))
  .catch(error => console.error("Lỗi:", error))
  .finally(() => console.log("Hoàn tất tác vụ Promise."));
18

Async / Await (Cú pháp bất đồng bộ hiện đại)

async/await là cú pháp Syntactic Sugar xây dựng trên nền tảng Promise, giúp lập trình viên viết mã bất đồng bộ phẳng và tự nhiên như mã đồng bộ (synchronous).

Async / Await with try...catch 
const delay = (ms) => new Promise(res => setTimeout(res, ms));

// Khai báo hàm async
async function fetchCourseData() {
  try {
    console.log("Đang tải dữ liệu...");
    await delay(1000); // Tạm dừng thực thi không gây nghẽn UI
    
    const data = { id: 101, title: "JavaScript Complete Guide" };
    console.log("Kết quả nhận được:", data);
    return data;
  } catch (error) {
    console.error("Xử lý ngoại lệ:", error);
  }
}

fetchCourseData();

Local Storage (Lưu trữ dữ liệu Trình duyệt)

localStorage cho phép lưu trữ dữ liệu dạng cặp key-value không có thời gian hết hạn ngay trên trình duyệt client của người dùng (tối đa ~5MB).

Phương thức Mô tả tác dụng
localStorage.setItem(key, value) Lưu dữ liệu vào bộ nhớ local.
localStorage.getItem(key) Đọc dữ liệu theo key (trả về chuỗi String).
localStorage.removeItem(key) Xóa phần tử theo key chỉ định.
localStorage.clear() Xóa toàn bộ dữ liệu trong domain.
Local Storage JSON Serialization 
// 1. Lưu trữ Object bằng JSON.stringify()
const userPreferences = {
  theme: "dark",
  fontSize: "16px",
  autoSave: true
};

localStorage.setItem("user_config", JSON.stringify(userPreferences));

// 2. Đọc và parse Object bằng JSON.parse()
const savedConfigStr = localStorage.getItem("user_config");
if (savedConfigStr) {
  const savedConfig = JSON.parse(savedConfigStr);
  console.log("Giao diện đã lưu:", savedConfig.theme);
}

ES6+ Features (Các tính năng JavaScript hiện đại)

Phiên bản ES6 (ECMAScript 2015) và các bản cập nhật hàng năm mang đến sự đột phá hoàn toàn cho ngôn ngữ JavaScript.

Các tính năng ES6+ vượt trội:

  • Template Literals: Chuỗi nội suy bằng cặp dấu backtick `Hello ${name}`.
  • Classes & OOP: Cú pháp hướng đối tượng sạch hơn class Student { ... }.
  • Private Fields (#field): Khai báo thuộc tính tư nhân ẩn trong Class.
  • ES Modules: Chia tách và xuất nhập module với export và import.
ES6+ Class & Private Fields 
// ES6 Class với Private Field (#)
class Developer {
  #salary = 2000; // Private field (không thể truy cập từ bên ngoài)

  constructor(name, stack) {
    this.name = name;
    this.stack = stack;
  }

  getDetails() {
    return `${this.name} làm ${this.stack} với mức lương bảo mật.`;
  }
}

const dev = new Developer("Trần Vũ Bằng", "JavaScript / React");
console.log(dev.getDetails());
console.log("Name:", dev.name);
// console.log(dev.#salary); // Lỗi SyntaxError! Thâm nhập bị chặn.
